# 링크나무

내 모든 링크를 한 페이지에 모아 하나의 URL로 공유하는 Link in Bio 서비스입니다.

## 배포 링크

- https://linknamu-beryl-alpha.vercel.app

## 기술 스택

- Next.js 14 (App Router)
- Tailwind CSS
- MongoDB Atlas (클릭 수 저장)
- Vercel (배포)

## 로컬 실행

```bash
npm install
npm run dev
```

`.env.local`에 MongoDB 연결 정보가 필요합니다. 이 파일은 커밋하지 않습니다.
